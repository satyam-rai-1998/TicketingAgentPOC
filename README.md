# Zendesk-like Ticketing POC

The app lives in [`fastapi-app/`](fastapi-app/README.md) — a Python/FastAPI
backend mirroring Zendesk's REST API shape and webhook behavior, plus an
admin dashboard and a public support site with a chat widget, built for
deployment on PythonAnywhere.

See [`fastapi-app/README.md`](fastapi-app/README.md) for setup, API docs,
and PythonAnywhere deployment instructions.

(An earlier Node/Express version of this POC was removed in favor of the
FastAPI rewrite, to match the PythonAnywhere deployment target.)
